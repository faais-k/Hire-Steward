# Hire-steward — Risk Register

**Reviewed:** 2026-10-28  
**Status:** Foundation 3 candidate-evidence code exists alongside compensation backend and PostgreSQL/CI configuration. Hosted CI verified `f47b9d1` on 2026-10-28 with PostgreSQL (73 passed, 0 failed, one upstream warning); Foundation 3 PostgreSQL coverage is not yet locally verified. Local Compose startup and broader operational verification remain outstanding.
**Scale:** Severity is qualitative (Critical/High/Medium/Low), not a quantified probability estimate.

## Risk acceptance rule

No unresolved High risk involving source permission, hard eligibility, consent, secrets, duplicate prevention, or uncertain external outcomes may be waived by a score, model output, successful click or UI-only check. Any live side-effect path remains disabled until its specific release gates and explicit user authorization are satisfied.
